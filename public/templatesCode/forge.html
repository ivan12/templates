Every decision in Forge was made to remove friction between you and your running code.

01 — BUILD SYSTEM

Native parallelism

Forge splits your build graph across all CPU cores automatically. No config, no workers, no tuning. Just instant parallelism out of the box.

02 — HOT RELOAD

Granular HMR

Forge's module graph knows exactly what changed. Only the affected modules reload — not your entire app. Updates appear in under 10ms.

~850ms

03 — TYPE SAFETY

First-class TypeScript

Forge uses esbuild for transpilation and the TypeScript compiler for type checking — running in parallel so you always get both, never one-or-the-other.

export interface Config {
  entry: string[]
  outDir: string

04 — ZERO CONFIG

Works out of the box

Forge detects your project type (React, Next, Vite, Node) automatically and configures itself. The config file is optional — and under 10 lines when you need it.
